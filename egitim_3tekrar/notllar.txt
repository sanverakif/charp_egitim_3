Global Operator ::
Ýlgili namespace e her yerden eriþmek isteyebiliriz. Global keywordu ile uygulama seviyesinde tanýmlama yaparýz. 3 þekilde olabilir.
cs.proj içerisinde þu tanýmlamalar yapýlýr. 
1.yöntem
<ItemGroup>
		<Using Include="test1"/>
		<Using Include="test2"/>
</ItemGroup>
2.yöntem
global using test1; global using test2; global using test3; global using System.Data.SqlTypes;
3.yöntem
global::test3.CA xx = new();
